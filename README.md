# Kanashi Collector

카나시 SOOP 후원 수집함 Windows 릴리스 및 자동 업데이트 저장소입니다.

## v1.3.0

- 공 수집 후원 규칙을 최대 5개까지 등록하고 우선순위 목록에서 확인·삭제
- 첫 번째로 일치하는 규칙을 기준으로 공 개수 계산
- 후원 수집 ON/OFF와 `공겜/켠왕` 50개당 1공 계산 추가
- 수집 항목과 게임별 최종 공 개수를 직접 수정하는 기능 추가
- 공 수집 설정 영역 스크롤 및 일반 채팅 중복·시청자 유형 필터 개선
- 시간·분·초 직접 입력, 증감, 시작, 일시정지, 초기화를 지원하는 타이머 탭 추가
- 현재 선택한 탭에 맞는 내장 설명서 추가
- 방셀·역팬·후원 공·일반 채팅 수집 조건 자동 테스트 보강

## v1.2.0

- 기존 핀볼 탭을 `공 수집`으로 개편
- 후원과 일반 채팅을 닉네임 기준으로 공 수집
- 건빵·팬·구독자·열혈 채팅 유형 필터와 중복 수집 설정
- Edge WebView2 기반 `나시볼` 탭 추가
- 공 수집 결과를 나시볼에 즉시 불러오기
- 기존 고정 스트리머 `kjhh0029` 자동 연결 유지

Windows 11은 Edge WebView2 Runtime을 기본 포함합니다. 이전 Windows에서는 Microsoft Edge WebView2 Runtime이 필요합니다.

## v1.1.0

- 일반 방송은 기존처럼 비로그인 우선 연결
- 연령제한·구독자 전용 응답 시 SOOP 계정 로그인 및 자동 재연결
- 로그인 세션 재사용, 로그아웃, 계정 변경
- 로그인 쿠키를 Windows DPAPI 사용자 범위로 암호화 저장
- 연결됨·오프라인·로그인 필요·네트워크/서버 오류 상태 구분

로그인 비밀번호는 저장하지 않으며, 브라우저 확장프로그램이나 브라우저에서 방송 데이터를 전달받지 않습니다. 수집 연결은 항상 EXE 내부에서 처리합니다.

## v1.0.2

- 부드러운 기계식 룰렛 회전음과 당첨 효과음
- 실행 시 업데이트 자동 확인
- 현재 버전 및 새로고침 버튼 표시
- 설치 시 바탕화면/시작 메뉴 바로가기 생성
- 설치 완료 직후 앱 자동 실행
