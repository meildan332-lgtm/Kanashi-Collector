# Kanashi Collector

카나시 SOOP 후원 수집함 Windows 릴리스 및 자동 업데이트 저장소입니다.

## v1.0.2

- 부드러운 기계식 룰렛 회전음과 당첨 효과음
- 실행 시 업데이트 자동 확인
- 현재 버전 및 새로고침 버튼 표시
- 설치 시 바탕화면/시작 메뉴 바로가기 생성
- 설치 완료 직후 앱 자동 실행

`dist/Kanashi-Collector-v1.0.2-Portable.zip`은 설치 없이 압축을 풀어 바로 실행할 수 있는 포터블 버전입니다.

수정 및 재빌드에 관한 내용은 [BUILDING.md](BUILDING.md)를 참고하세요.
